## 每天的开发过程

正式日志写 `IPTV聚合器-开发日志.md`，**新的一节写最上面**（倒序，最新先看到），不覆盖旧内容。
`.workbuddy/memory/YYYY-MM-DD.md` 只做当日速记，不作为交付物。

## 规矩

1. 《开发计划》§1 是唯一的状态表，每轮改一行；别处不重复描述现状。
2. 待办只写在《开发计划》§2，做完就地删，不留「已完成」花名册。
3. 每天收工写日志，不攒着补。记：做了什么、为什么、踩了什么坑、下一步。
4. 文档只写「现在是什么、接下来做什么」，不写沿革、不写来历。
5. 新增/删除模块、引入外部资产，必须同步更新《资产统计表》。
6. 上游仓库只读：不提交、不提 PR、不 force-push。所有改动只进 `tmadmao/tvbox-source-aggregator`。
7. **日志倒序**：最新的一节插在文件最上面；「待办速查」作为附录永远放最后。
   理由：查日志 90% 是为了看「最近发生了什么」，正序要滚几千行才能看到昨天的结论。
